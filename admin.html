How VIP Access Works

1. Select a VIP subscription plan.
2. Generate a unique access code.
3. Give the code to the intended VIP user.
4. The user redeems the code from the VIP page.
5. The server activates the subscription and calculates its expiry date.

Each VIP code is single-use.
